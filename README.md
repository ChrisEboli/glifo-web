# Glifo per iPhone

Versione web di Glifo, da aprire in Safari e aggiungere alla schermata Home:
https://chriseboli.github.io/glifo-web/

Questo repository contiene solo il sito compilato. Il codice di Glifo è in un repository privato.
Nessun dato dei clienti è qui: le anamnesi restano nel foglio Google e si leggono solo dopo l'accesso con un account autorizzato.
